AI Coding Ability Comparison

🎯 Objective

To compare the ability of different AI models in coding by having them create portfolio websites based on the same source material.

Prompt given to each AI:
"Read this web https://iqbalshd.github.io/Portfolio/ then create my portfolio using that information."
Claude Sonnet 4 View Portfolio ChatGPT-5 View Portfolio Google Gemini 2.5 Pro View Portfolio
Each AI was given the same prompt and access to the original portfolio.
Compare their interpretations, design choices, and coding approaches.
